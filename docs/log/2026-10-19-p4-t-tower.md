# 4.6 tower

Branch `claude/p4-t-tower`. `gen/v1/types/tower/TowerType.java` (registered in `Types.java`).

- **Massing**: a 7..11 square-ish shaft (own draw, half the time square), 4..10 storeys from the spec, never wider than half
  its height (`g.y(n)/2`), so height >= 2 x width by construction; if the storey count cannot satisfy it, storeys drop first
  (and, with a low `maxHeight`, a tower of fewer storeys is built). Variants by draw: plain shaft (45 %), 1-2 storey plinth
  with the shaft inset 1 (30 %), set-back top storey / bell chamber (25 %). One core through all storeys from
  `MassingOps.core` over the stack (the narrower part sets the minimum width: core length + 2, +2 more with a plinth/crown).
  Style storey heights are used but `groundExtra` is ignored (a 5-high ground storey would need a 6-long core).
- **Tiny floors**: interior 5x5 with the 5x2 stair core leaves one 5x3 chamber per floor (Gallery cutaway: stair + one room
  per storey, rooms-reachable passes). Accepted as intended. Room program: entry (chest, table), chambers (chest, bed, table).
- Limits: lot 9x9..15x15 (margins 1/1/1), storeys 4..10, maxGrade 2. `V1PropertyTest` 4 lots x 250 seeds green.
- No new MassingOps methods; shared tests: `MainTest` edited as T-highrise did (assert only `failing: 0`, `--types house`).
- **Gallery** `tower-medieval` (noise, cutaway at storey 2) and `tower-flat` (plain): 16 towers per camera, 0 violations.
  Before roofs merged: gables on every top; after: flat + parapet (>= 6 storeys) or gable. Towers read as tall and narrow with
  distinct silhouettes (plinth, stepped top); the uniform window bands still look like a thin high-rise: slit windows and
  stone-ish facade are for the facade step / a style (REVIEW entry).
- Diversity (256 seeds, 11x11): storeys 2.76, roomsPerStorey 2.9, windows 4.8 (width/depth are fixed by the spec). Floors in
  the test are on footprint/shape counts (>= 6 footprints, >= 3 shapes).
- Mutant: `g.y(n)/2` -> `/1` fails `towersAreAtLeastTwiceAsTallAsWide...`. Golden `tower.txt` regenerated after the roofs merge.
- r2: merged S and Fa; tower golden regenerated (only tower.txt changed); check --types tower 0..400: 51,328 cases, 0 failing incl. entrance-reachable; gallery now shows half-timbering, plinth and sills, which reads as a timber tower rather than a thin high-rise. Slit windows left as known issue.
