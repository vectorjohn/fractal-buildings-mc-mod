## Round 3 (lead-coder): the quay cut was window-dependent
- **Cause**: each tile traced the quay contour through its own window (tile + 56) and graded every run it saw as a whole. A run longer than the window was clipped differently by each tile: at s7_m3 d47_m15 saw the x 7676 run from z -2388, d47_m14 from z -2304 (both to -2180). `Grading.profile` anchors every 8 columns from the run's start and clamps over the whole run, and `quayParts` cuts the meeting nearest the first steep column, so d47_m14's shorter run went steep near its clipped start and cut its nearest meeting, the border street at z -2240; d47_m15's longer run did not. Even a meeting pin differed (z -2180: 86 vs 85, from an earlier, also clipped quay). R1 only exposed it (the narrower demoted street changed the pins); it was latent for any long quay.
- **Fix** (pointwise): `Districts.Build.settlementQuays` traces the contour once over every waterfront tile the settlement plans (+16 blocks), keeps quay columns only inside those tiles (so the contour there is never clipped), grades all runs in canonical order, and is cached per source and probe through the new `SkeletonSource.shared` (as the junction field). `quayWholes()` picks the runs near the tile. A run now ends at the border of the settlement's waterfront tiles (no tile beyond draws it).
- **Test**: `QuayWindowTest` (s7_m3, tile pairs d47_m15/d47_m14 and d47_m14/d48_m14, a fresh source per tile): the quay runs within 8 blocks of the border must be identical. Failed before the fix (the two runs above), passes after.
- **Cost**: the first waterfront tile now pays for the settlement's quays: `HubSquareGateTest` gate-desert-badlands hub tile 371k probe calls (budget 220k -> 450k); whole settlement 28 % fewer calls (1.88M -> 1.35M), s7_m3 16 % fewer (3.39M -> 2.86M), wall time unchanged. Entry in `docs/PERFORMANCE.md`.
- **Squares** (`SQUARE_ONE_IN` 4 -> 1): sound. The decision is a hash of the crossing (kx, kz) and the pointwise arterial predicate, listed by the cell that owns the tile, one square per tile; it reads no tile window.
- **city-check** (after the fix): world 12345 cells 152 sites 0 failing, world 987654321 cells 150 sites 0 failing, 9 gate sites (`--scenes auto:2`) 0 failing; `tile-border-agree` 0 everywhere. s7_m3 repro: 0 violations.
