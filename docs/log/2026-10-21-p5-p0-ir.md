# P5 P0: settlement IR, fixtures, brief

Item: Phase 5 plan step P0 ([plans/phase5.md](../plans/phase5.md)). Branch `claude/p5-p0-ir`. The foundation SK, DL, DB, V1, V2 build on.

## What was done

- **Scene additions** (additive, `docs/IR.md` "District scenes"): `terrain.water` (`TerrainPatch` optional water array,
  `sampleWithWater`), top-level `ground` boxes on `SceneDoc` (6-arg constructor kept), roles `road`/`paving`/`ground`,
  layer `ground`; writer, strict reader, `ir-valid` (ground boxes must be layer ground, storey -1); palette and colour
  lines in all seven styles; viewer `ir.ts` parses both, `ROLES`/`LAYERS`, role colours.
- **Brief**: `core/gen/Brief` on `GenRequest` (null = old behaviour), `SpecPolicyV1` intersects storeys and takes the street mask
  (front forced, `allStreets` types keep 15); new `SpecPolicyV1.reliefOk` shared with `ClassTable`.
- **Probes**: `CoarseProbe` (lattice-only, `of(...)`), `BiomeIds`, `CountingProbe`, `ProbeSpecs` `river:` and `biomes:split:` joined with `+`.
- **Settlement model** `core/settlement/`: records for every object of both formats, `SettlementJson`/`DistrictJson` (byte-stable
  writers, strict readers), `Ids`, `ClassTable`, `SampleSettlement` (`sample()`: 2 x 2 tile town, river, plains/desert split, bridged main
  road, street, lane, market, 40 lots, one district scene of 12 buildings with briefs; `big(n)`), `core/check/SettlementChecks`
  (`lot-in-tile`, `lots-disjoint`). CLI `sample-city --out-dir D [--big N]`. Fixture `viewer/fixtures/settlement/sample/` (settlement
  4 KB, districts 1-3 KB, scene 425 KB).

## Decisions and deviations

- `SitePart` of the plan is `SettlementSite` itself (plan.site); `Pt`, `Cell`, `Rect`, `StyleWeight`, `DistrictInfo` added. `RegionView` /
  `FixedSiteView` are not in P0's step list and not written (SK's).
- `Quarter.id` is an int (its index); `kind` an enum. The district reader, not the constructor, rejects a lot outside its tile.
- Style palette tests that whitelist blocks (`DesertStyleTest`, `TaigaStyleTest`) got the new blocks.
