# QUAYFAST step 4: screened seed and partner scans

Branch `claude/p6-quayfast-4` (coder). Plan: [quayfast.md](../plans/quayfast.md) step 4.

## Done

- `QuayTrace.near`: a scan cell is read only if some column of its closed cell (x in [8i, 8i+8], z in [8j, 8j+8]) inside the tile's m box passes `Bank.maybeOk` (`cellMaybe`, every column tested, memoised per column in `maybeMemo`). The scan prefetch is now one box per row run of kept cells (was the whole scan box); the node memo takes the list of fetched boxes (never forgotten).
- `partnersOf`: the same screen on each cell round a run column (no box limit; a candidate must pass `ok`, so a cell with no `maybeOk` column holds none). `all()` passes no screen.
- `QuayTuning.screenScan` (default on) turns the screen off for before/after counts; answers are the same either way.
- Exactness: an ok column has `maybeOk`, lies in its closed cell and in the box, so its cell is kept; cell tests are over all columns, not corners.

## Surprises

- First version kept the `maybeOk` memo trace-wide (a `ConcurrentHashMap` per column). A trace serves a whole settlement, so it grew with the settlement and `:planner-core:test` and `:cli:test` JVMs ran out of memory. The memo is now local to each `near` call and each `partnersOf` call (a `TreeMap`: `DeterminismLintTest` rejects `HashMap`).
