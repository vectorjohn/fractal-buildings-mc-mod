# 3.3 Generator v0 (S3)

Done: `core/grammar/{IntSplit,Choice}`, `core/gen/{GenRequest,Generator,ShellSource,Styles}`,
`core/gen/v0/{SpecPolicyV0,ShellGeneratorV0,InstancePassV0,GeneratorV0}`. `GEN_VERSION = 1`.
Rules follow "Generator v0 rules" in `docs/plans/phase3.md`.

## Choices within the plan
- `Choice` picks the room count (options 1/2/3 weighted 2/3/2); storeys, sizes, door positions and
  room weights come from `Draws` seeded by `Hash64.hash(specSeed, "spec" | "layout" | "front-door")`.
- Room 0 gets minimum width 5 in the `IntSplit` when storeys > 1; the room count is reduced until
  the minimums fit (no "drop partitions" loop needed).
- Stair opening box = the three step columns (x0..x0+2, y slab+1..+3, z d-2). Partition doors sit
  on every storey at the same z. Windows skip partition columns, the front-door column (storey 0)
  and stair columns on the front and back walls.
- Roof height: rows = ceil(shorter side / 2); bounds height = 4n + 1 + rows (matches the sample scene).
- Ridge along x when w >= d, else along z (rows then run along z, gable ends at z = 0 and d-1).

No deviations from the plan.
