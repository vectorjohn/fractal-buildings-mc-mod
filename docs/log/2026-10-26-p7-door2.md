# DOOR2: wide-door steps on sloped blocks

Repro: `block`, seed 22, lot 100x80, noise terrain, style with `doorWidth` 2 (a test-only `test-wide-door` extending medieval): `steps-reach-ground` failed on a 1-wide door (o248), not on a wide one.

Root cause: in `InstancePassV1.steps` a wide door's (or stoop's) landing candidates come from `stoopCandidates`, which only checks the building grid, not cells earlier doors' flights use; the candidate loop then clears `blocked` on its cells. A later wide door's long landing along the lot edge (62 cells) overwrote the end of an earlier door's flight with a level block, so that flight ended on a raised deck, not the ground. Fix: drop landing candidates that contain a cell with `flightTop` set (an earlier flight or landing). Doors whose front is already on an earlier landing are still skipped as before.

Verification: `WideDoorStepsTest` (every type, 40 seeds x each test lot, test-wide-door style) failed with 1 failure before the fix (block seed 22), passes after; full `:planner-core:test` green (goldens unchanged: plain/medieval have doorWidth 1); `check --seeds 0..29` see report.
Added: `StyleLibrary.get` accepts unindexed `test-*` styles found on the classpath (never listed by `ids()`).
