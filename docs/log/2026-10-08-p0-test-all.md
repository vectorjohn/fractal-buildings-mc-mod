# 0.6 scripts/test-all.sh (2026-10-08)

Added `scripts/test-all.sh`: runs every test layer and prints a per-layer summary
(pass/fail/skipped, test counts, new screenshots, log paths). `--no-client` skips
layer 5. Re-execs under `nix develop` if `IN_NIX_SHELL` is unset; works from any
cwd/worktree. Per-step output goes to `build/test-all/<step>.log`. Exit 1 if any
step fails. Bash + coreutils/grep/sed/awk only (no python in the shell); no flake change.

Steps (each detected from `./gradlew -q tasks --all` or the viewer's `npm run --json`,
reported "skipped: not present yet" when missing):
- L1 `planner-core`: `:planner-core:build` (tests + `checkNoMinecraft`); counts from JUnit XML.
- L1 `cli`: `:cli:build`.
- L2 `determinism`: a Gradle task whose name contains `determinism` if one exists, otherwise
  the counts of JUnit classes named `*Determinism*` that ran in the steps above.
- L4 `mod`: `:mod:build`, plus `:mod:runGameTest*` if such a task exists (same invocation);
  game test count from the vanilla "All N required tests passed" log line.
- L1 `viewer`: `npm ci` if `node_modules` is missing or older than the lockfile, then `npm test`;
  counts from Vitest's "Tests" line.
- L3 `viewer-shots`: first npm script named screenshot(s)/shot/smoke/e2e/playwright/gallery
  (optionally `:suffix`).
- L5 `client`: `flock <main root>/.claude/heavy.lock xvfb-run -a ./gradlew :mod:runClientGameTest`;
  records `/proc/loadavg`. Main root comes from `git rev-parse --git-common-dir`.

Verified (run): `--no-client` from `/tmp` passes (planner-core 1/1, cli 2/2, viewer 3/3; others
skipped as not present). A deliberately failing Vitest test made the viewer step `fail` and the
exit status 1; without `--no-client` the client step reported "not present yet". JUnit parsing
checked on a synthetic report with failures and skips. Client layer not exercised (no task yet).

Notes: don't run the script under the heavy lock (it takes it itself and would deadlock).
Game test count patterns are guesses until 0.5 lands; if they don't match, the summary says
"no count in log" and the step's status still comes from the Gradle exit code.
