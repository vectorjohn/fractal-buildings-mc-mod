# p5-viewer-palette: per-building palettes in district 3D

The gate pack's 3D frames drew a whole district in the first building's style, so mixed districts could not show the biome mix.

- `render.ts`: `colourOf` now uses each voxel's own building style (`scene.buildings[v.building].shell.spec.style`); an explicit `opts.style` still forces one palette. Both the instanced and the face-mesh paths go through `colourOf`. `main.ts` passes `state.style` (undefined = per building) instead of the effective style.
- Ground boxes (roads, paving) and the district terrain have no building, so `styleLocator` (voxels.ts) picks the style of the nearest building footprint centre; terrain takes `groundTint(style)` (palettes.ts: plains/medieval green, jungle dark green, desert sand, snowy white, taiga dark green). Chosen over a biome tint because scenes carry no biome (terrain dumps have it, scenes don't); a stand-in, so the tint edge is a Voronoi seam between buildings, not the real biome border. Tint only applies with `colour=palette` and the district/face terrain path; single-building views and role colours are unchanged (gallery single buildings use the cube path).
- Tests (`renderDistrict.test.ts`): a district with two styles gives more shell colours than the same district all-plains, in both mesh paths, and all-plains matches; terrain colours gain the desert tint; an explicit style overrides. Mutation: making `colourOf` use building 0's style fails the two-palette tests. `npm test`: 129 passed.
- Gate pack: `npm run city` for the 9 gate cities, `gate-pack-scenes.mjs`, `vite build`, `GATE_PACK=1` capture of those 9 (44 fly frames re-encoded to JPEG with new `viewer/scripts/png-to-jpg.mjs`, Chromium canvas, quality 0.82; the repo has no PNG-capable JPEG tool in the dev shell). Plan frames were not replaced. cities/ is 7.7 MB (budget 8). Looked at: jungle/savanna hub (before: all plains red tiles on pale green; after: jungle moss roofs and plains tiles mixed, green patches follow style), metropolis mixed (desert towers on sand, plains houses on green), border (jungle roofs).
