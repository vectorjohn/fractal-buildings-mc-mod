# 0.4 Smoke path (2026-10-08)

**Pipeline:** `Planner.smokeBox(seed)` (planner-core, pure) returns a provisional `SmokeIr` record (`irVersion` 0, `size`, ordered `boxes` with `min`/`size`/`role`): floor, wall, roof layers of a 5x5x5 box. `cli` `IrJson` hand-writes deterministic JSON (fixed key order, fixed formatting); `gen --seed N --lot WxD --style S [--out FILE]` writes it (stdout otherwise; lot/style unused for now). The viewer's `Ir` type + `parseIr` validator mirror it (`viewer/src/ir.ts`); `main.ts` loads the bundled `fixtures/box5.json` or `?ir=<url>`, and sets `window.__viewerReady`.

**Verification**
- `IrJsonTest`: two runs byte-identical; JSON has version and roles; committed fixture equals CLI output (fails if stale).
- `voxels.test.ts`: parses the CLI fixture, 125 voxels in 5^3, >= 2 roles; `parseIr` rejects bad version/shape.
- `npm run screenshot` -> `viewer/out/smoke.png`: looked at it: red roof, beige walls, blue floor on a grid over a dark background. Test asserts non-background fraction > 3% and reddish/beige fractions > 0.5% (measured 17% / 6% / 8%).
- Mutations: fixture role edited -> `viewerFixtureMatchesCliOutput` fails (needed the fixture declared as a Gradle test input in `cli/build.gradle`); wall colour set equal to floor -> e2e colour-fraction assertion fails.

**Surprises:** headless Chromium got no WebGL until `DISPLAY` was unset (dead `DISPLAY=:2` in the agent shell; ANGLE tries xcb). nixpkgs' locked playwright-driver is 1.63.0, while `nix eval nixpkgs#...` (registry) said 1.59.1; pin follows the lock. Added `@types/node` (devDependency) for `node:fs` in tests.

**Changes to build files:** `flake.nix` (+playwright-driver.browsers, PLAYWRIGHT_* env), `viewer/package.json` (+@playwright/test 1.63.0 exact, +@types/node, `screenshot` script), `viewer/tsconfig.json`, `cli/build.gradle` (fixture as test input).
