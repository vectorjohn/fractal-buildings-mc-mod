# P5 V1: plan view

Branch `claude/p5-v1-planview`. Plan step V1 (5.5 part 1); the ROADMAP checkbox stays open for V2 (the later of the two ticks).

## What

- `viewer/src/settlement.ts`: strict parsers for `fb-settlement/1` and `fb-district/1` (errors start with the JSON path, plan version 1 only,
  district id must match ix/iz, bridge ranges and lot-in-tile checked), gzip-aware fetch reusing V0's `decodeBytes` (regionmap.ts).
- `viewer/src/planDraw.ts` (pure): view transform and zoom (1/16..8 px/block), the LOD rule (lots at >= 0.5 px/block, else per-tile density),
  layers parsing, coarse raster (hillshade, water, biome, mask, density, quarters), terrain-dump raster, drawing, hit tests.
- `viewer/src/plan.ts` + `plan.html`: the page (pan, wheel zoom, hover, click, layer panel, URL state, lazy district loading, `__planReady`,
  `__planApi`). Added to the vite inputs. Did not touch render.ts or ir.ts.
- Docs: VIEWER.md "Plan view"; NOTES line.

## Verification

- `npm test`: tsc + vitest, 14 files (settlement round trip over the fixture, 10 strict failures, gzip; transform, zoom anchoring, LOD loads only
  visible districts, layers, rasters, hit tests).
- `e2e/plan.spec.ts` (FB_PORT=4731): 5 pass: sample overview (nothing loaded, road colour present), sample detail (4 districts loaded, lot type
  colours and street colour fractions), hover/click/scene link and layer toggle, bad directory reports an error, `sample-city --big 4096`
  (1024 districts): overview 45-81 ms (bar 3 s), worst of 20 pan redraws 1.9 ms at 1 px/block (bar 100 ms), 64 districts / 1739 lots drawn; load ~12.
- Screenshots opened (`viewer/out/plan/`): sample detail shows the river with a tan bridge deck, main road with gates, lots coloured by type in
  rows facing the street, the market landmark; big overview is the density heat map over tiles; big detail is the lot grid with streets.
- Mutation check: not run (parser rejections are each a test that fails if the check is removed).

## Decisions and notes

- `?city=<dir>` is a URL directory (not a path), so tests serve fixtures via Playwright routes; FB_GALLERY `gallery-data/city/<name>/` also works.
- Violations draw as red squares at each cell's (x, z) footprint (min 6 px) from the settlement and loaded districts.
- Road `points` are drawn offset +0.5 (column centres); width is not clipped to the 45-degree geometry (fine at plan scale).
- No real SK/DB output was available, so only the sample and `--big` were exercised; the big sample has two roads and no gates or landmarks.
