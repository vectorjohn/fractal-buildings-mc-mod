# IrJson.read (follow-up to 3.1)

- `IrJson.read(String)` -> `SceneDoc`, implemented in package-private `ir/IrReader.java` on top of `JsonReader`. Write path untouched.
- Strict: wrong `format` (the only version field; `genVersion` is a generator version), missing required keys, wrong types, non-integer numbers (`1.5`, `7.0`), out-of-range ints, unknown enum names, non-string seeds all throw `IllegalArgumentException` starting with the JSON path (`$.buildings[0].shell.openings[0].kind: ...`). Record-constructor checks (positive box size, etc.) get the path prefixed. Unknown extra keys are ignored.
- 64-bit seeds (`seed`, `spec.specSeed`) are parsed from strings; test covers 2^53+1 and Long.MIN_VALUE.
- Extra check: stored `specHash` must equal `SpecHash.of(spec)`, so a hand-edited spec can't pass silently.
- Tests: `IrReadTest` (11): fixture round trip byte-identical and equal to `SampleScenes.house()`, passes `IrValidator`; scene with violations (null building, escaped text, null terrain) round trips; rejection cases. Mutation: disabling the hash check fails a test.
- `:planner-core:check` passes.
