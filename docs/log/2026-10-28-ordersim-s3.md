# ORDERSIM S3: the order harness (2026-10-28)

Branch `claude/p6-ordersim-s3`, plan [ordersim.md](../plans/ordersim.md) (section "S3 as built"). Test-only code in `mod/src/test/java/dev/fractalbuildings/mod/ordersim/`; no production change.

## What was done

- `Scenario` (inner n x n chunk window, decorated window one wider, sim window two wider; pieces per chunk from `DistrictStructure.buildingPieces` / `GroundStructure.groundPieces`; the reference raster of every piece over the sim window as a `Long2IntOpenHashMap`).
- `SimOrders` (forward, reverse, shuffle-1..N, spiral, checker), `SimFeatures` (the real vanilla features, hashed and scripted calls, `LakeVeto.vetoes` before every lake, per-key stats).
- `OrderSim.runAll` / `run`: per chunk, per `Decoration` step: our pieces through `TilePiece.write` at the structures' step, the features of the step, at the top layer the road-feature passes, then promotion. Orders run on a small pool (`parallel`), baseline = first order; audit (write log with `StackWalker` frames, C5, C6) in the first two.
- `SimCompare`: C1 (errors, zone violations by our code, `WorldPlanners.FAILURES` delta), C2 (ledger against reference, duplicates, digest across orders), C3 (world against raster through `SpillKinds`), C4 (claimed cells against the baseline, with last writer of each cell; strict only if `spaced`), C5 (write contracts), C6 (fixpoint of a second sweep).
- `SimReport`: one line per run like the order test, spill histograms, features, writes by pass, first bad cells with neighbours and writers; stdout and `mod/build/ordersim/<scenario>.report`.
- `SimLevel`: method table cached per `Method` (was a string concat per call), `environmentAttributes()` (lava tick delay in promotion), `trackWriters` apart from the write log, `StackWalker` only for our writes.
