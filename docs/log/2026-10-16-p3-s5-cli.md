# 3.4 CLI (S5)

Done: `gen`, `batch`, `check`, `bench` and (from S7) `diversity` in `cli/`, each a small command class behind a `switch` in `Main` (add one `case` per command). Shared parsing in `Opts`, request building in `Scenes`, the check/bench cross product in `Matrix`.

- `gen --seed --lot WxD [--at X,Z] [--front] [--style plain] [--terrain flat:64] [--check] [--out]`; recorded terrain with no `--at` centres the lot on the dump grid.
- `batch --seeds A..B --lot ... --out-dir DIR`: `seed-N.json` in order plus `index.json` `{"style","lot","terrain","seeds"}`; checks embedded unless `--no-check`. Matches the viewer's `gen/<style>/index.json` reader (V2).
- `check`: cross product (parallel per seed, reported in fixed order), markdown report, exit 1 on any violation. `bench`: single-thread per-stage mean/p50/p95 plus `/proc/loadavg`.
- Removed `SmokeIr`, `Planner.smokeBox`, cli `IrJson`, `box5.json`, `IrJsonDeterminismTest`; `SceneFixtureTest` guards `viewer/fixtures/v0-seed1.json`.
