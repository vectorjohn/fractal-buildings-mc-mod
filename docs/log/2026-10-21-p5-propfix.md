# p5-propfix: V1PropertyTest skips policy rejections

`V1PropertyTest -Dfb.propertyScale=10` failed one shop case of 16000 (14684, seed 3671, lot 14x9, `noise:3671:90:2:25`). Cause: `SpecPolicyV1` rejects shops on lots steeper than 1 in 12 by design ("lot ground relief 3 over 14x9 ... too steep for a shop"); the sampler can still draw such a lot. It was not an entrance-reachable failure (the wallwalk log said so; corrected by a NOTES line).

Fix (test only): `V1PropertyTest.run` counts an `IllegalArgumentException` whose message starts with `lot ground relief ` and ends with `, too steep for a <this type id>` as a skipped case and prints `V1PropertyTest <type>: N of M cases skipped`. Any other exception, or any invariant violation, still fails. More than 2% skipped fails the type, so the skip cannot hide a generator rejecting most lots.

Verified: scale 10, all types incl. curtain and bastion: 0 failing, shop 1 of 16000 skipped; `:planner-core:test` passes. Before the change the same run failed shop (11 tests, 1 failed).
