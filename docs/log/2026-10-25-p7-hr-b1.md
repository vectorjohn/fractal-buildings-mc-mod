# 2026-10-25 P7 HR-B1: tower massing

Branch `claude/p7-hr-b1`, plan [highrises.md](../plans/highrises.md) step B1 (ROADMAP 7.13, DS-32, DS-22).

## What changed (`types/highrise/` only)

- `TowerProgram`: kind per storey (LOBBY, TYPICAL, BANQUET, OPEN, SUITES, STAIRHOUSE); specials only for 12+ storeys
  (1 under 20, 1-2 under 36, 2-3 above), on candidate storeys (first above podium, first of each later tier, last below
  crown or top), never adjacent, never next to the lobby; heights 6 / 6 / 4 / 4 (lobby, special, typical, stair house);
  `band(s)` facade keys; `read(c)` / `of(massing, draws)` re-derive it from the final massing.
- `TowerBlock`: the core block in building coordinates (stairwell, guard row for `sd` 4, 3x3 shaft on either side, hall,
  partitions) and `fits(tier)`. `SD = 3` is the one constant; `HighriseMassing.build(c, sd)` lets tests run 4.
- `HighriseMassing`: places the block in the podium (hall centred, or block centred in a 23+ deep interior, x centred
  +-2, snapped to the back wall when 1-3 rows would remain, drawn / flush / centred x fallbacks), shrinks tier insets until
  every tier holds the block, builds the grid from the programme, adds the stair house over the whole block
  (parent top tier) and one `Core(0..n+1)`. Capacity counts the stair house and `ROOF_ROOM`.
