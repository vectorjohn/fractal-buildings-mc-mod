# 4.9 Viewer for the Phase 4 galleries

Branch `claude/p4-v-viewer`, plan step V.

- **Roof shading** (`viewer/src/shading.ts`): per building, per column the top `roof` voxel gives a heightfield; slope
  by central/one-sided difference of neighbours (ridge and flat = untinted), Lambert of the tilted normal against a fixed
  world sun, mapped so flat = 1 (0.5..1: slopes facing away from the sun darken, the rest keeps the flat colour). Applied as a colour factor in both `role` and `palette` modes. Gallery before/after:
  the old roofs were one flat dark red; now each gable side is its own shade, the sun side lighter.
- **Style colours** (`styles.ts`): bundles the style JSONs, resolves `extends`, picks `colours[role][hash % n]` with a
  `Math.imul` hash; unknown style -> `plain`. `STYLE_PALETTES` is gone; the viewer's style list is the file list.
- **Presets as files**: `gallery-presets/*.json` (the four Phase 3 batches + `fixtures`), `gen-gallery.sh/.mjs`,
  `gallery.spec.ts` loops presets x cameras (`FB_PRESETS` filter), checks as before (> 2 % non-background per cell, 0 violations).
  The page reads `?dir=<preset>&camera=...&cut=...`; `?fixture=<name>` renders one bundled scene in one big cell.
- **Cutaway** camera: top pose, roof layer and storeys above `cutStorey` hidden (`visibility.ts`), frame from `cutBounds`.
  `house-medieval` and `fixtures` use it.
- **Hook markers**: small cubes per hook kind in the interior group (scaled instance matrices, honours the storey limit).
  Untested against real output (no hooks are generated yet); Vitest covers placement under all four rotations.
- **Tall fixture**: `tall50`, not `tall60` (see ROADMAP note). Appended at the end of `TestMassings.all()`.

Verification: `npm test` (58 tests), `npm run gallery` (22 e2e: 5 presets x cameras + 2 roof-shading), mutation: roofShades
returning 1 fails 2 Vitest tests and the `top` e2e (dark 58 / light 60). Tall 16-cell page: 3.1 s (load 2.1).
