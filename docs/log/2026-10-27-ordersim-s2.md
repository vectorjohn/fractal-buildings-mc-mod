# ORDERSIM S2: SimSites, ScenarioFinder

Branch `claude/p6-ordersim-s2`. Test-only code in `mod/src/test/java/dev/fractalbuildings/mod/ordersim/`.

- `SimSites`: a copy of core's test-only `GateWorld` (rows of `gate-sites.tsv` as `WorldProbes`, `site()`, `planner()` = `WorldPlanner.forSite`, inline, default caches).
- `ScenarioFinder(planner, site, groundProbe)`: core API only. Reads the planned tiles within 2 of the centre tile, their buildings and ground pieces, and rasters pieces (`planner.raster`) into per-column summaries (street surface y and block, AIR headroom top, building air/solid).
  - `densestWindow(n)`: SC1 window (most building pieces, then ground pieces; nearest the centre; lowest z, x).
  - `lakeAtDugInWall` / `lakeUnderBox` / `lakeFarBelow`: SC2 a/b/c. (b) is a grid that meets only the 12-block deep foundation, not the box; (c) is the control below it, not vetoed. `lakeBox` copies `LakeVeto.box` (a test pins it to the mod's; swap for the S0 seam later).
  - `trunkSpots()` / `trunkSpot(kind)`: SC3 BURIED, ON_SURFACE, CUT_HEADROOM: a 2x2 base straddling a street edge row on a chunk line (street column plus open-ground neighbour across the line), kind from the surface vs natural ground. Scans 6x6 windows outward from the densest window.
- Determinism: all scans in sorted tile/piece/column order; the test compares output on the same planner and a fresh one.

## Verified (`ScenarioFinderTest`, 9 tests, gate-temperate-city)
SC1 window cx=89 cz=-590 (6x6): 33 buildings, 27 ground pieces, 2336 building-air columns, 570 street columns on chunk lines. SC2 a/b/c found, vetoes true/true/false and `claimsNear` agrees. SC3: all three kinds found (CUT_HEADROOM only outside the densest window, hence the outward scan). Planner + pieces build 3 to 12 s depending on load. Mutation: lake (b) y moved to `box.y - 2` fails `sc2UnderBoxIsOnlyTheDeepFoundation`.
