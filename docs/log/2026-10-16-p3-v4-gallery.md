# 3.8 Seed gallery (V4)

- `viewer/gallery.html` + `src/gallery.ts`: 4x4 grid of 16 seeds from a CLI batch, one `WebGLRenderer` with scissor/viewport per cell, HTML label per cell (seed, voxels, violations; red border on violations). The sun follows the camera so all presets are lit alike.
- `src/presets.ts` (+ `presets.test.ts`): `front-left`, `back-right`, `top`, `front`, relative to the building's world bounds and the lot's front facing; fixed FOV 35 and distance factor.
- `scripts/gen-gallery.sh` (`npm run gen`): CLI batch seeds 0..63, 20x20, styles plain and medieval, terrain `noise:7:64:6:32` and `flat:64` (`<style>-flat`). `npm run gallery` = gen, typecheck, build with `FB_GALLERY=1`, Playwright `e2e/gallery.spec.ts` (16 tests: 2 styles x 2 terrains x 4 presets; checks 16 cells, 0 violations, every cell > 2 % non-background, no page errors).
- Deviations: data goes to `viewer/gallery-data/` (not `public/gen`) and `dist-gallery/`, switched by `FB_GALLERY=1` in `vite.config.ts`: a `public/gen/plain` would have been picked up by the default `/` source and broken the existing smoke/controls specs. Added the flat-terrain variants (brief asked for flat and sloped).
- Also: `FB_PORT` for the Playwright preview port; stale box5 comment in `source.ts` fixed; CLAUDE.md gallery line; gitignore.
- Looked at: all 16 PNGs in `viewer/out/gallery/` (opened 6 in detail). Buildings vary clearly in footprint, height, roof pitch and storeys; no violations, nothing floating. Plain vs medieval differ only by palette at generator v0 (same shapes). Top view is flat-shaded (roof reads as one colour blob); flat seed 5 shows a seam in the grass strip on the left (terrain/site-box edge, harmless).
