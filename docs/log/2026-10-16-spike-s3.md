- Result: pieces' writes identical in all orders (0 differing chunks), world solid plan blocks identical (0), 0 blocks written twice, 1 connected road component across district borders, `/locate` finds the city, plan rebuild after eviction byte-identical. Three mutants (overlap, gap, shared counter) each fail the test.

## Surprises

- The server game-test world is flat with structures disabled; used client game tests instead.
- Vanilla whole-chunk hashes are not order-independent (455-575 of 576 chunks differ), so the criterion became "blocks our pieces own".
- Vanilla trees (dark oak) overwrote 2-4 of ~91k solid blocks with step `surface_structures`; `top_layer_modification` fixed it.
- My own shell had `WAYLAND_DISPLAY` set at first (before `scripts/client-test.sh` existed on the base branch): three early client launches died with "GPU timeout"; they may have briefly opened a window on John's desktop. After that the driver stripped the Wayland variables and set `SDL_VIDEODRIVER=x11`.
