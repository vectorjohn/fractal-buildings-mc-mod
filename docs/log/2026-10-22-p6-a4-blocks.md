# P6 A4: block mapping (6.1 palette half)

`mod/.../block/BlockMapper` maps (`Role`, block id, `Shape`) to a Minecraft `BlockState`; `ShapeTable` maps a
full block to its stair/slab variant. Pure function, cached in a `ConcurrentHashMap`.

- Properties are applied **by name and value string** (`facing`, `half`/`type`, `hinge`, `axis`,
  `north/east/south/west`, `up`), so doors, stairs, slabs, logs, panes, fences and walls need no per-class code
  and blocks lacking a property ignore it. Booleans for panes/fences, `low`/`none` for walls (`up` false when a
  wall runs straight through). Doors are closed (`open=false`).
- `state(Role.STAIR, id, shape)`: a stair-capable cell with a `facing` becomes the material's stair block
  (`oak_planks` to `oak_stairs`, `bricks` to `brick_stairs`, `cut_sandstone` to `sandstone_stairs`);
  with no facing it stays a full block. Stair `facing` = ascent direction (vanilla meaning).
- Unknown/typo id: `minecraft:stone` plus one warning per id. No stair variant: full block, one warning.
- Palette keys covered: all roles in every style including `road`, `paving`, `ground`, `deck` (the Phase 5 known
  issue) and any other key present (the `rail` key from p6-railings is handled by the same code: fence/wall
  blocks connect through `Shape.connect`). Railings' palette change was not on run-phase6 when I merged; the
  test iterates whatever the palettes contain, so it covers `rail` automatically once it lands.

Tests (`BlockMapperTest`, 9, plain JUnit with bootstrapped registries, ~1 s): every palette id of every style is a
real non-air block; district roles present in each style; style x role x shape sweep (about 4k states, none air);
stair/roof ids all have stair and slab variants except `terracotta`, `brown_terracotta`, `red_terracotta`,
`moss_block`, `snow_block` (vanilla has none; they stay full blocks; the test pins this set); stair facing/half,
door facing/half/hinge in all combinations, pane/fence/wall connect, log axis, slab type, unknown id.
Mutation: made `hinge` unmapped, `doorsFaceHalfHinge` failed. `:mod:build` (includes the hello-hut game test)
passes after merging run-phase6.
