# 2026-10-21 p5-v2-district3d (5.5 part 2)

**Done.** The main viewer page renders district scenes: terrain, water, road/paving ground boxes, all buildings, with a fly-through camera.

- `src/mesh.ts` (pure): `exposedFaces` (one `MeshData` per layer, faces only between solid and non-solid; an `Occupancy` index with numeric keys; terrain
  counts as solid), `groundCells` (boxes in order, `air` clears), `terrainTops` (air ground boxes lower a column), `terrainMesh` (heightfield + sides + 3-block
  skirt; a column whose top block is a road voxel drops its top quad), `waterMesh` (runs of equal level along x).
- `src/render.ts`: instanced path unchanged for small scenes; face path above 200k building voxels or `?mesh=faces`; `?exterior=1` drops interior and hooks;
  new groups `water` and `ground`; stats on `root.userData.stats`. District scenes always use the heightfield terrain.
- `src/fly.ts` + `main.ts`: `?camera=fly` (three r186 `FlyControls`), `?stops=x,y,z,yaw,pitch;...` (first applied, `]`/`[` cycle, `__viewer.goStop(i)`).
- `voxels.ts`: `buildingVoxels` rewritten on a dense grid (same output, faster), `sceneVoxels` cached. `ir.ts`: opening kind `arch` accepted (5.11 not merged yet when written; trivial merge).
- Layers `water`, `ground` added to `ALL_LAYERS`.

**Verified.** `npm test` (116 vitest: meshing counts 1/2/54 faces, hollow cube, layer-hidden faces, winding, air cut lowers one column, water runs, stops, URL state);
`e2e/district.spec.ts` (sample district at three stops with water/road/grass colour fractions, layer switch removes water, 6x6 tiled synthetic district under 20 s);
real DB scenes (`viewer/out/district/*.json` from DistrictScenesTest, copied from the DB worktree's output) all render with roads and river (looked at `real-d0_0-ext.png`,
`real-d1_1.png`, sample stops 0-2, `big.png`). Mutation: not run formally; the winding and count tests fail on a wrong direction table by construction.
**Numbers** (SwiftShader, load ~25): sample 10k voxels: 17k triangles/frame, 90 ms; 432-building synthetic district: 365k voxels, 3.06M built / 615k drawn triangles, 1.4 draw calls, ready in 5-7 s, ~640 ms/frame software.

**Decisions / known issues.** Storeys slider and hook markers do not work on the face path (no per-storey data). Ground is instanced below the threshold (12 triangles per
cell; 190k triangles for a sample district) and merged above it. Yaw convention: 0 looks -z, 90 looks -x (three.js). Bridges render as plain `ground` boxes (DB uses role `ground`).
