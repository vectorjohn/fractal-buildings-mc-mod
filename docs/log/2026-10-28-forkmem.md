# FORKMEM: memory-aware test forks

`planner-core/build.gradle`: `maxParallelForks` = max(1, min(6, cpus/3, (budget - 1536 MB) / (2048 MB heap + 512 MB))). Budget = tightest cgroup v2 `memory.max` from the build's cgroup (`/proc/self/cgroup`) up to the root, else `MemAvailable`, the lower of the two. One lifecycle line per build says the choice and why. `mod` only sets `maxHeapSize` (no fork setting), so nothing to change there.
