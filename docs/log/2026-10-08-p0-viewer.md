# 0.1b viewer skeleton (2026-10-08)

Added `viewer/`: Vite + Vitest + strict TypeScript + three.js. `src/main.ts` sets up scene, camera, lights, grid, OrbitControls and renders a hard-coded 5x5x5 demo IR as an InstancedMesh coloured by role. `src/ir.ts` is a **provisional** IR type (list of role-tagged boxes); item 0.4 defines the real smoke IR, Phase 3 the real one. `src/voxels.ts` has the pure `irToVoxels` (sorted, de-duplicated, later boxes win).

Scripts: `npm test` = `tsc --noEmit && vitest run` (headless, exits); `npm run build` = `tsc --noEmit && vite build`; `npm run dev`.

Verified from a clean `node_modules`: `npm ci`, `npm test` (3 tests pass), `npm run build` pass. Mutation: making earlier boxes win in `irToVoxels` fails the override test. The page was not opened in a browser (no Playwright until 0.4); `dev` not run.
