# FLYCAP: fly-through captures only stable frames

Test code only (`FlyThroughClientGameTest`). Cause: `hasRenderedAllSections` and `hasChunk` are true while section meshes are still compiling, so shots showed a patch of world floating in sky (12345-metropolis-5-slope at any load; two more at load 55+).

Fix: `stableShot` takes a screenshot every 20 ticks until two in a row agree (48x27 grid of mean colours, mean abs diff under 4 of 255, sky fraction within 0.02; at most 8 tries, a cap logs a warning and keeps the last). Probe PNGs are deleted. `time set noon` is re-issued before each frame and each retry.

CITYQ's slope-camera height cap is not on run-phase6 (CITYQ unmerged), so nothing to revert; CITYQ code untouched.
