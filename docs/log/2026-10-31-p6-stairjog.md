# 6.31 STAIRJOG: entrance flights run straight

Item: ROADMAP Phase 6 "Playtest 2026-10-31 bug list". John's shots 03.10.40 / 03.12.04 / 03.14.45 (metropolis s4_m2, lot d26_m7.l2, seed 1573336981619055086).

## Cause (found by instrumenting the search)
The lot has 13 free cells west and 14 east of the triple door, so room was not the problem. `InstancePassV1.searchRuns` is a breadth-first search from the landing; a flight from a landing must end on the lot's street row, and a straight run along the wall (2 risers, rest, 3 risers, rest, 1 riser, then step off sideways onto the street row) is exactly as long as the jog out into the lot-edge row. The tie went to the jog because the search expands "out" first. Nothing in the search preferred fewer turns.

## What changed
- `InstancePassV1.steps`: new outer `mode` loop. Mode 0 runs the whole rail-pass / candidate search with `searchRuns(..., straight=true)` (no direction change after the first move; only the final step onto the ground may leave the line); mode 1 is the old search. So a straight flight on either side of the door wins over a jog at any rail pass; where none fits, the old route is kept. (This is John's idea, "start the flight one cell further along", realised as a search rule instead of a wider landing: the landing is still the door width, the flight starts beside it.)
- `GeneratorV1.search`: where the result still has `flight-turns` (a jog), set the building back further (new `JOG_SETBACKS` {3,0},{4,1},{6,1},{8,2}; architect's order, report playtest1031-qs-architect: straight run first, then setback) and keep the first placement that is railed and jog-free. Not changed: another face for the main door (architect step 3) and the case where no setback fits (step 4: the check lists it).
- `DoorChecks.flightShape` (design warnings `flight-turns`, `flight-rail`, run with `DoorChecks.warnings` so `check` and `city-check` list them): reads the placed tread boxes, finds turn cells (a tread with two path neighbours at right angles), flags two turns exactly one riser apart on one flight (two on the same level are one half landing), and a rail post on a tread cell. The amendment's "no rail post in a landing cell" is checked literally (rail and tread in the same column); the rail posts beside the old turn are gone because the turn is.
- Tests: `StairJogTest` (the real lot on the pt1573 dumps: every tread in the wall row, no `flight-*` warning), `FlightShapeTest` (jog flagged, straight, L and half landing pass, rail on tread flagged).
