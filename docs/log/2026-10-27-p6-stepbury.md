## 6.13 STEPBURY: steps and door approaches claimed as air

- `InstancePassV1.headroom` (core): after every flight is placed (and before the rails), an `AIR` site box of 3 blocks (`HEADROOM`) over each tread and landing, each cell a flight ends on the terrain, each of the dig-in's own exit steps (`SiteLevel`) and each cell in front of an entrance door leaf. Only cells the shell leaves free (site boxes raster after the shell, so an AIR box over an eave or wall would erase it). The boxes start above the standing level: `SiteGround` is unchanged, so invariants and `DoorRise` read the same ground.
- It applies to every building type that has an entrance door (raised doors, high-rises, halls), not only S2's dig-in types. The world side needs nothing new: the piece writes (and the ledger claims) the air, which removes what `beard_thin` raised into the flight and what a tree put there before the pass; trees that arrive later are TREEIN.
- Test: `StepHeadroomTest` (every STAIR site box has its 3 cells above claimed by an AIR box or the shell, 3 terrains x all types except the wall types whose stairs climb inside the wall band). It first failed on a bug of mine (`run < 0` as "no run" fails at negative world y): the test is able to fail. Goldens regenerated (`GoldenDigestV1Test`): all 11 types, the site box lists changed.
- `InstancePassV1.HEADROOM_ENABLED` is a test switch for the client control.

## 6.14 TREEIN: foliage in building air

- `BuildingAirClear` (mod), called from `RoadFeature.place` (every overworld chunk, top-layer step, after the chunk's own features and structure pieces): for the buildings whose lot is within 12 blocks of the chunk, rasters the piece over the chunk +-12 and, in cells that come out as `Role.AIR`, removes natural leaves (not persistent), vines and logs whose connected logs touch natural leaves; then `FoliageClear.run` takes what the cuts left hanging. Same argument as `SpillClear`: the chunk that decorates a tree always covers the cells that tree can reach (<= 12), so the end state is independent of chunk order. Nothing the ledger gives as a solid block changes; hooks (furniture) are not leaves/vines/tree logs.
- Cost: counters `CALLS`/`NANOS` (printed by the client test).
