# 4.6 T-shop: the shop type

Branch `claude/p4-t-shop`, package `gen/v1/types/shop/` (`ShopType`, `ShopMassing`, `Shopfront`).

- **Massing**: main block as wide as the envelope (so the ground front room spans the lot front), 5-high ground storey, 2-4 storeys; optional rear wing (back house, 15+ deep lots, own `sideCore` when the shared core candidates are blocked by the wing strip) and, in styles with jetties, a front-only jetty (main starts at z 1 then). Falls back to no jetty, plain block, fewer storeys.
- **Facade program** wraps `FacadePass`: main ground front becomes door (centre) + `shopfront` bays (2-3 wide) + 1-wide `pier` bays, plus a TRIM fascia along the top wall row. **Openings program** wraps `OpeningPass` and cuts the shopfront windows (sill 1 / 2 high, or sill 0 / 3 high in 1 of 4). **Interior** wraps `InteriorPass`: shop room (use `shop`, via the type's `RoomProgram`) gets chest/light; a counter hook is placed near the front; a bed and table are added upstairs if the planned rooms have none (narrow floors are one stair room).
- Pier bays use a custom kind so the interior pass reserves the front row: it cannot cut the front room across (found: default splits made the room 5 of 12 wide).
- Shared infrastructure: `TypeLimits.oriented` (narrow deep test lots for E/W fronts, V1Case and CLI Matrix), `MainTest` pins `--types house`. No shared pass behaviour changed; house golden unchanged.

Verification: `V1PropertyTest` shop (1600 cases) green; `ShopTypeTest` (everyShop... 2 styles x 4 envelopes x 256 seeds; theChecksCanFail with 3 IR mutants; diversity: rear wings 247, jetties 361, full glass 232 of 1024; storeys 2-4); code mutant (windows 1 wide) fails the property test; `fractal-cli check --types shop --seeds 0..199`: 25600 cases, 0 failing. Gallery `shop-medieval|plain|flat` viewed (front, front-left, cutaway): shopfront with door and wide blue windows under a dark fascia, floors with window rows, rear wings visible in cutaway, counter (green marker) behind the front windows.

Known issues: lots under 7 wide unsupported; no awning/sign; counter hook sits one row behind the display windows (looks right in cutaway, judge in game).
