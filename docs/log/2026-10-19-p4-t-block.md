# 4.6 City block (step T-block)

Branch `claude/p4-t-block`. New type `block` (`gen/v1/types/block/`): a street block filled by a ring of row units around a courtyard.

## What was done

- `BlockMassing`: north and south rows span the width and own the corners; west and east columns run between them. Units are 6-12 wide along the street and 8-10 deep (neighbours 0-1 deeper), 1-5 storeys (a block draws a base height from the spec and each unit +-1, forced to >= 3 distinct heights when there are >= 8 units). Neighbours share one wall strip and are declared `Massing.partyWalls` (no door). A column is at least 2 narrower than the corner units it hangs from, so it shares a wall with the corner unit and never meets the next unit of the row (M6). In half the blocks one joint of the north or south row is a 3-4 wide alley instead of a party wall, so the courtyard is reachable from the street; otherwise it is closed (a yard behind the units). Every ground mass is an entrance mass; every unit above 1 storey has its own core on the side away from its street (a unit with no room for a core stays 1 storey). Retries (24 draws, thinner rings) until the courtyard is >= 24 % of the lot and `MassingCheck` passes.
- `BlockFacade`: the shared facade pass, then each unit's door is moved to its own street face (rows: north/south; columns: west/east); the shared pass may choose the courtyard side because the whole lot is a street.
- `BlockType`: margins 1 on every side (steps of plan step S need the margin on every door side), `allStreets`, storeys 2-5, `maxGrade` 3, lots 40x40, 52x70, 64x48, 100x80, 60 property seeds per lot (about 1 s).
- `Types.java`: one `r.add(new BlockType())` line. MassingOps unchanged (the block's layout and cores are in its own package; `MassingOps.core` is tied to a back row at +z).
- `MainTest`: the default-matrix case count and the 12x10 lot are no longer hard-coded (same edit as the high-rise step).
- Golden `block.txt` added; `house.txt` unchanged by this step.
- Gallery presets `block-plain`, `block-plain-flat`, `block-medieval` (cutaway), `block-medieval-flat` (100x80).

## Verification

- `:planner-core:test :cli:test` green. `BlockTypeTest`: 1200 blocks (2 styles x 4 lots x 150 seeds): all pass `MassingCheck`, every unit is an entrance with its own core, shared strips are party walls, courtyard >= 20 % of the lot, >= 3 distinct heights on all blocks (all have >= 8 units), 43 % have an alley; 160 shells: exactly one exterior door per unit, facing its street, no opening in any party wall (checked only on storeys both units span: above a lower neighbour the wall is an outer wall and may have windows); diversity floors (256 seeds, medieval 64x48: Jaccard 0.619, near-dup 0, 239 signatures; plain 40x40: 0.543, 0, 214; floors 0.50 / 0.01 / 170).
- `fractal-cli check --types block --seeds 0..499` (before merging roofs): 64,000 cases, 0 violations; after merging roofs and interiors, seeds 0..199: 25,600 cases, 0 violations.
- Mutants: shared facade pass without the street fix -> `doorsFaceTheStreet...` fails; unit heights not varied -> `massingsAre...VariedHeights` and `diversityFloors` fail.
- Gallery (medieval 64x48 noise, plain flat 64x48, cutaway, front): a ring of joined units around a green courtyard on every seed, heights varying between 1 and 5 storeys, after merging the roofs step each unit has its own roof (gables, hips, dormers; party walls separate the roof groups, lower units close against taller neighbours), partitions visible in the cutaway (interiors step), alley gaps visible as breaks in the ring on about half. All cells 0 violations.

## Notes

- Units read as one long facade from the front: storey bands are shared (one grid), so the seam between two units shows mainly as a height step, a roof change or a different window rhythm. See REVIEW.

## Round 2 (after Fa and S merged)

- S's `entrance-reachable` fails for a block on slopes: one slab level for the whole ring means doors on the low side are up to (lot / run) blocks above ground and their flights jam each other along the margin (per-wing ground levels are Phase 6.3). So: margins 5 on every side, `maxGrade` 24, min lot 52x52 (test lots 52x52, 52x70, 64x56, 100x80; courtyard >= 22 % of the lot enforced, was 24 %/40x40), and the CLI `Matrix` uses gentle default terrains (`flat, plane 1:24, hill 4/120, noise amp 1`) for types with maxGrade > 3. `V1Case` draws noise instead of the recorded crop when maxGrade > 3 (real terrain is steeper).
- Storey cap now follows `maxHeight` (extreme-ground test).
- `BlockFacade` needed no change for Fa's API. `check --types block --seeds 0..199`: 25,600 cases, 0 violations (incl. entrance-reachable). Gallery: Fa's timber, plinths and per-band windows make units read as separate houses.
