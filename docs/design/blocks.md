# Block reference

Generated by `scripts/design-blocks.sh` for **Minecraft 26.3**; don't edit by hand. Block ids and variants come from the game's block registry (data generator `--reports`), colours from the block textures in the client jar, **Vanilla** from the structure templates in the server jar; Biomes / styles, Uses and High-rise are hand-written in [blocks-notes.md](blocks-notes.md) (edit there, then rerun the script). The same table, without Vanilla and group rows, is injected into `.claude/agents/*.md` between the BLOCKS markers.

				Columns: **Blocks** lists each base block id, its colour as sRGB hex (the mean of its texture; 				names in **Colour** are approximate, for the first block), and in brackets the variants that exist 				as `<stem>_<variant>` (stem = the id, or the id without `_planks`/`_block`/`_wool`, or with bricks->brick, tiles->tile: quartz_block -> quartz_stairs, stone_bricks -> stone_brick_wall). **wood set** = stairs slab fence fence_gate door trapdoor button pressure_plate 				sign hanging_sign shelf ("-x": that one is missing); **wood** = the all-bark `_wood`/`_hyphae` block; 				**+waxed** = a `waxed_` copy exists (it never oxidises). `{dye}` = the 16 dye colours. A block not 				listed with a variant has none: never invent `X_stairs` etc. **Vanilla** = vanilla structure 				templates using the family (20+ blocks). **High-rise**: Y fits tall urban buildings, accent = trim 				only, N = keep to small or rural buildings.
